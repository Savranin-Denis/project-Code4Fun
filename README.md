# 🍰 Солодка Майстерня (Sweet Workshop)

Солодка Майстерня — це сучасний та адаптивний веб-сайт для кондитерської з
можливістю перегляду каталогу десертів, фільтрації товарів та оформлення
онлайн-замовлень.

## Про проєкт та задачі

Проєкт розроблено для надання користувачам зручного інтерфейсу при виборі
авторських кондитерських виробів.

- 📱 **Адаптивність:** Зручний перегляд на будь-яких пристроях (mobile, tablet,
  desktop).
- 🔍 **Зручна навігація та фільтрація:** Можливість швидкого пошуку десертів за
  категоріями.
- 📦 **Інтерактивність:** Ознайомлення з деталями продукту у модальному вікні та
  швидке перемикання на форму замовлення.
- 💬 **Зворотний зв'язок:** Розділи з FAQ, відгуками та контактами.

## 🛠 Технології

- **HTML5:** Семантична верстка, HTML Partial Bundler.
- **CSS3:** Flexbox, CSS Grid, CSS Variables, методологія БЕМ.
- **JavaScript (ES6+):** Модульна архітектура (ESM), Async/Await, Fetch API, DOM
  Manipulation.
- **Збирач проєкту:** [Vite](https://vitejs.dev/)
- **Нормалізація стилів:** `modern-normalize`

## 🚀 Як запустити проєкт локально

1. Клонуйте репозиторій:

```bash
  git clone https://github.com/Savranin-Denis/project-Code4Fun.git
```

2. Перейдіть у папку проекту

```bash
  cd project-Code4Fun
```

3. Встановіть залежності

```bash
  npm i
```

4. Запустіть сервер

```bash
  npm run dev
```
